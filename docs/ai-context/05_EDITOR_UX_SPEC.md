# 05｜简历编辑器 UX 规范

## 1. 编辑器目标

用户的主要任务是：

**写内容，而不是做设计。**

因此编辑器不能让用户面对复杂排版参数。

---

## 2. 推荐布局

桌面端：

```text
顶部工具栏
--------------------------------------------------------------
左侧内容编辑      中间 A4 实时预览        右侧样式设置
约 340px          自适应                 约 280px
```

中间预览可以滚动。

---

## 3. 左侧：内容编辑

使用 Accordion / Section 列表。

例如：

```text
基本信息
求职意向
个人优势
教育经历
工作经历
项目经历
技能
证书荣誉
自我评价
```

点击 Section 展开表单。

---

## 4. 列表型内容

例如工作经历：

```text
工作经历

[ 某互联网公司 / 产品经理 ]
2023.01 - 至今
[编辑] [删除]

[ + 添加工作经历 ]
```

编辑时可以使用抽屉、展开区域或弹窗。

第一版优先选择最容易维护的方案。

---

## 5. Description 编辑

工作/项目描述使用多条 bullet。

用户操作：

- 添加一条
- 删除一条
- 上下排序

第一版不需要富文本编辑器。

禁止：

- 自定义颜色
- 任意字号
- 表格
- 内嵌图片
- HTML 编辑

---

## 6. 中间：简历预览

预览是实际模板渲染结果。

要求：

- 接近 A4 比例。
- 编辑内容后快速更新。
- 显示分页边界。
- 不显示编辑控件。
- 不依赖 Office。

---

## 7. 右侧：样式

仅包括：

### 模板

显示当前模板。

点击后打开模板选择。

### 主题色

固定 5～8 个颜色。

### 字体

固定 2～4 个组合。

### 密度

宽松 / 标准 / 紧凑。

### 头像

显示 / 隐藏。

---

## 8. 顶部工具栏

建议：

```text
← 我的简历

产品经理简历
已保存

预览
导出 PDF
```

如果需要加入 AI，后续增加。

---

## 9. 排序

Section 可以上下排序。

MVP 可以使用：

- 上移
- 下移

不强求第一版加入复杂 Drag & Drop。

稳定后再升级拖拽排序。

---

## 10. 空状态

空 Section 在简历预览中不显示。

编辑区仍然显示入口：

```text
项目经历
还没有项目经历
[ + 添加 ]
```

---

## 11. 删除保护

删除工作经历、项目经历等重要内容时需要确认。

不要每一个 bullet 删除都弹确认框。

---

## 12. 移动端

MVP 可以明确：

**编辑器优先支持桌面浏览器。**

移动端第一阶段只保证：

- 能打开。
- 能简单查看。

不要求完整编辑体验。

这样可以显著降低第一阶段复杂度。
