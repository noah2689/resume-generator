# 02｜MVP 产品规格

## 1. MVP 页面范围

第一版只需要 4 个主要页面。

### 页面 A：我的简历

作用：

- 新建简历
- 查看已有简历
- 修改简历名称
- 复制简历
- 删除简历
- 进入编辑

不需要：

- 团队协作
- 分享权限
- 文件夹
- 版本树
- 高级搜索

---

### 页面 B：新建简历

第一版只提供两种入口：

1. 从空白创建
2. 使用示例数据创建

后续再增加：

- 上传旧简历
- AI 对话生成
- JD 生成

MVP 不要在入口阶段加入这些复杂功能。

---

### 页面 C：简历编辑器

布局：

```text
┌──────────────────────────────────────────────────────────────┐
│ 返回 | 简历名称 | 保存状态                   预览 | 导出 PDF │
├──────────────┬─────────────────────────┬─────────────────────┤
│              │                         │                     │
│ 内容编辑区   │       A4 简历预览        │     样式设置        │
│              │                         │                     │
│ 基本信息     │                         │ 模板                │
│ 教育经历     │                         │ 主题色              │
│ 工作经历     │                         │ 字体                │
│ 项目经历     │                         │ 密度                │
│ 技能         │                         │                     │
│              │                         │                     │
└──────────────┴─────────────────────────┴─────────────────────┘
```

第一版右侧不需要 AI Chat。

---

### 页面 D：模板选择

可以做成编辑器内部抽屉或弹窗。

每张模板卡只显示：

- 缩略图
- 模板名称
- 布局标签
- “使用”按钮

MVP 只有 3～6 个模板即可。

---

## 2. 内容模块

第一版支持：

- 基本信息
- 求职意向
- 个人优势
- 教育经历
- 工作经历
- 项目经历
- 技能
- 证书 / 荣誉
- 自我评价

每个模块支持：

- 新增条目
- 编辑
- 删除
- 上下排序
- 显示 / 隐藏

---

## 3. 编辑原则

### 允许用户控制

用户可以控制：

- 文本内容
- 条目顺序
- 模块顺序
- 模块显示/隐藏
- 模板
- 主题色
- 字体
- 页面密度

### 不允许用户控制

用户不能直接控制：

- x/y 坐标
- 文本框宽高
- 任意 margin 数值
- 任意字号
- 任意行高
- 任意绝对定位

---

## 4. 样式设置

MVP 只开放下面几项。

### 模板

例如：

- 简约单栏
- 商务单栏
- 左右双栏

### 主题色

提供固定色板。

例如：

- 黑灰
- 深蓝
- 蓝色
- 墨绿
- 酒红

用户不需要完整取色器。

### 字体

只提供经过验证的中文字体组合。

原则：

- 浏览器能稳定显示。
- PDF 环境能稳定获得。
- 不依赖用户电脑安装。

### 密度

只提供：

- 宽松
- 标准
- 紧凑

密度统一影响：

- 字号
- 行高
- 模块间距
- 条目间距

不让用户分别调几十个数值。

---

## 5. 保存

建议自动保存。

最小要求：

- 内容编辑后延迟保存。
- 显示“保存中 / 已保存 / 保存失败”。
- 刷新页面后内容仍存在。

---

## 6. PDF 导出

PDF 是第一阶段唯一正式导出格式。

要求：

- A4 页面尺寸。
- 中文不乱码。
- 不出现浏览器默认页眉页脚。
- 页面背景、分割线和主题色正常。
- 分页不能出现严重文字重叠。

MVP 不要求 Word 导出。

---

## 7. 错误状态

必须设计：

- 保存失败
- 加载失败
- PDF 生成失败
- 模板加载失败

禁止只在 console 中报错。

---

## 8. 第一版演示数据

系统内置一份完整中文产品经理示例简历，方便：

- 开发时预览。
- 验证模板。
- 自动化测试。
- 演示产品。

之后还可以增加：

- 应届生示例
- 技术岗位示例
- 财务岗位示例
